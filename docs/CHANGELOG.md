# Changelog

## [1.0.0] - 2026-10-09

First public release of Audio Forge.

- Convert between MP4, MP3, FLAC, and M4A.
- Edit title, artist, album, date, and JPEG/PNG artwork.
- Save matching formats without re-encoding; validate outputs before replacing files.
- Windows 98-inspired menus, beveled controls, property tabs, and original pixel icons.
- Native macOS window with internal minimize, maximize/restore, and close buttons.
- English by default, with Simplified Chinese and Japanese interface options.
- Standalone Apple Silicon installer for macOS 15 or later.
- Audio-focused shared LGPL FFmpeg/LAME build and reduced Python service runtime.
- MIT-licensed application source, documented third-party licenses, source archives,
  automated tests, and reproducible build instructions.
